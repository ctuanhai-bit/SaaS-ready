# Security Policy

## Reporting

Please report suspected vulnerabilities privately to the project maintainers.
Do not include credentials, personal data, production logs, certificates, or
private keys in public issues.

## Supported Configuration

- Change the documented local administrator password before shared use.
- Keep API encryption keys, database passwords, storage credentials and TLS
  material outside Git.
- The bundled Compose credentials are for isolated local development only.
- Third-party payment and refund integrations are outside the community build.
